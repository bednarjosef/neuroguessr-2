① GATE
smallest set of cells holding 95 % of the posterior mass (median ~42 cells, hard cap 400) → the candidate pool the matcher may search
Alone, this branch bottoms out at ~104 km median — a cell is ~34 km across, and its centre is the best answer it can ever give.
why the gate is loose
A tight gate (top-5 cells) throws away the answer 40 % of the time. At 95 % mass the right cell is inside 92–98 % of the time — so the whole remaining error is matching, not looking in the wrong place.
3 · retrieval branch → which exact photo
4.2 M
place head A (on CLS)
residual MLP 1024→2048→1024, zero-init output (starts as identity).
Trained so cosine similarity decays with distance: positives = any image within 10 km, negatives closer than 50 km masked as false.
